int ptiOmpMTTKRPHiCOO ( ptiSparseTensorHiCOO const *const  hitsr,
ptiMatrix *  mats[],
ptiIndex const  mats_order[],
ptiIndex const  mode,
const int  tk,
const int  tb 
)

Matriced sparse tensor in HiCOO format times a sequence of dense matrix Khatri-Rao products (MTTKRP) on a specified mode

Parameters
[out]mats[nmodes]the result of MTTKRP, a dense matrix, with size ndims[mode] * R
[in]hitsrthe HiCOO sparse tensor input
[in]mats(N+1) dense matrices, with mats[nmodes] as temporary
[in]mats_orderthe order of the Khatri-Rao products
[in]modethe mode on which the MTTKRP is performed
[in]scratchan temporary array to store intermediate results, space assigned before this function

This function uses support arbitrary-order sparse tensors with Khatri-Rao products of dense factor matrices, the output is the updated dense matrix for the "mode".
